# Universal Quant Tournament

Run institutional walk-forward strategy selection, Bayesian Monte Carlo risk gating, leverage-aware bracket sizing, and human-approved execution on MetaTrader 5 or Alpaca via `universal-quant-tournament-mcp`.

## Prerequisites

Verify that the `universal-quant-tournament` MCP server is connected (`npx -y universal-quant-tournament-mcp`) with:
- `RAPIDAPI_KEY` set for tournament, Monte Carlo, and bracket-building endpoints.
- **Alpaca (optional):** `ALPACA_KEY_ID`, `ALPACA_SECRET_KEY`, and `ALPACA_PAPER="true"` (default to Paper unless the user explicitly specifies Live) for `sync_or_execute_alpaca`.
- **MetaTrader 5 (optional):** Windows MT5 desktop terminal open with Algorithmic Trading enabled for `sync_or_execute_local_mt5`.

## Available MCP Tools

| Stage | Tool Name | Purpose |
| :--- | :--- | :--- |
| 0 (Optional) | `sync_or_execute_local_mt5` | Pull live broker OHLCV candles, account equity, and leverage from the local Windows MT5 terminal. |
| 0 (Optional) | `sync_or_execute_alpaca` | Sync live Alpaca Paper/Live account equity, buying power, open positions, and open orders via REST API v2. |
| 1 | `run_multi_strategy_tournament` | Pulls ForexFactory macro calendar (`forex_factory_macro_calendar`), classifies HTF regime, filters session liquidity hours, checks candle confirmation (Engulfing, Rejection Pinbar, or Displacement close), and runs the 8-strategy two-stage OOS walk-forward backtest. |
| 2 | `run_monte_carlo_stress_test` | Runs a 1,000-path Bayesian OOS Monte Carlo simulation and Half-Kelly risk assessment using the winning strategy's entry, SL, TP, and validated win rate. |
| 3 | `build_universal_bracket_order` | Generates risk-sized, leverage-aware bracket payloads for Alpaca (Equities/Crypto), MT5 (Forex/CFD/Metals with 100 oz Gold lot sizing & USD/JPY cross-rate conversion), and Tradovate/TradingView Webhooks (Futures). |
| 4 | `sync_or_execute_local_mt5` | Executes an approved `mt5_mql5_order_send` bracket order on the local Windows MT5 terminal **only after explicit user confirmation**. |
| 4 | `sync_or_execute_alpaca` | Executes a confirmed `alpaca_bracket_order` payload generated by `build_universal_bracket_order`, or cancels an open Alpaca order. |

## Workflow Instructions

Execute these stages in strict sequence. Never skip the Monte Carlo risk gate or submit/cancel a live order without explicit user confirmation.

1. **Sync Live Broker Data (Optional)**
   - **MetaTrader 5:** Call `sync_or_execute_local_mt5` in sync mode to pull live broker OHLCV candles, account equity, and leverage.
   - **Alpaca:** Call `sync_or_execute_alpaca` in sync mode to retrieve live account equity, buying power, open positions, and open orders.

2. **Run Top-Down Macro & Walk-Forward Tournament (`run_multi_strategy_tournament`)**
   - Call `run_multi_strategy_tournament` for the requested symbol, timeframe, and session liquidity window.
   - Surface all five outputs clearly:
     - **Macro Calendar Risk:** Upcoming ForexFactory high/medium impact events (`forex_factory_macro_calendar`).
     - **HTF Structure & Regime:** Higher-timeframe trend/regime classification.
     - **Session & Candle Confirmation:** Whether the entry bar confirmed via Engulfing, Rejection Pinbar, or Displacement close inside active session hours.
     - **Tournament Winner:** Top-ranked strategy from the 8-strategy two-stage OOS walk-forward backtest with validated win rate, entry, SL, and TP.
   - **Hard stop:** If a high-impact red-folder event blocks the window, candle confirmation fails, or no strategy clears OOS thresholds, stop and recommend sitting out.

3. **Run Monte Carlo & Half-Kelly Risk Gate (`run_monte_carlo_stress_test`)**
   - Pass the winning strategy's `entry`, `stop_loss`, `take_profit`, and validated OOS `win_rate` into `run_monte_carlo_stress_test`.
   - Report the 1,000-path Bayesian OOS drawdown distribution, risk-of-ruin metrics, and Half-Kelly sizing output.
   - **Hard stop:** If the setup fails the Monte Carlo or Half-Kelly risk gate, halt and state the exact failing metric. Do not build an order.

4. **Build Risk-Sized Bracket Payload (`build_universal_bracket_order`)**
   - Call `build_universal_bracket_order` for the target venue:
     - **Alpaca:** Equities and Crypto (`alpaca_bracket_order`).
     - **MetaTrader 5:** Forex, CFDs, Metals (`mt5_mql5_order_send`, including 100 oz Gold lot sizing and USD/JPY cross-rate conversion).
     - **Tradovate / TradingView Webhooks:** Futures.
   - Present the complete trade ticket (Venue, Paper/Live Mode, Symbol, Direction, Share/Lot Size, Leverage, Entry, Stop Loss, Take Profit, and Dollar/Percent Risk).

5. **Human-in-the-Loop Confirmation & Execution (`sync_or_execute_alpaca` / `sync_or_execute_local_mt5`)**
   - Pause and ask the user to explicitly reply **`Confirmed`** before submitting any order or cancellation.
   - **Alpaca Execution / Cancellation:** After explicit confirmation, call `sync_or_execute_alpaca` to execute the `alpaca_bracket_order` payload (or cancel a specified open order ID) and return the order ID and status.
   - **MT5 Execution:** After explicit confirmation, call `sync_or_execute_local_mt5` with the `mt5_mql5_order_send` payload and return the ticket ID and status.
   - **Tradovate / TradingView:** Output the verified bracket payload ready for webhook dispatch.

## Error Handling

| Failure Condition | Required Agent Action |
| :--- | :--- |
| Missing `RAPIDAPI_KEY` | Direct the user to add their RapidAPI key for `universal-quant-strategy-tournament` to `mcp.json` or `claude_desktop_config.json`. |
| Red-folder news conflict | Flag the exact `forex_factory_macro_calendar` event and block execution until the window clears. |
| No OOS winner or no candle confirmation | Display the tournament summary and advise **no trade**. |
| Monte Carlo / Half-Kelly gate failure | Report the drawdown or ruin breach and halt before calling `build_universal_bracket_order`. |
| Alpaca auth / insufficient buying power | Verify `ALPACA_KEY_ID`, `ALPACA_SECRET_KEY`, and `ALPACA_PAPER` env vars, or check buying power via `sync_or_execute_alpaca`. |
| MT5 local connection failure | Confirm the Windows MT5 desktop terminal is open, Algorithmic Trading is enabled, and the local Python IPC bridge is running. |

## Example

**User prompt:**
> Sync my Alpaca Paper account, run the quant tournament and Monte Carlo stress test on `NVDA` (15m), and prep a bracket order if it passes.

**Expected agent flow:**
1. Calls `sync_or_execute_alpaca` to pull live Paper account equity, buying power, and open positions.
2. Calls `run_multi_strategy_tournament` to verify ForexFactory macro news, HTF regime, session liquidity, candle confirmation, and the 8-strategy OOS winner.
3. Calls `run_monte_carlo_stress_test` on the winning setup's entry, SL, TP, and validated win rate.
4. Calls `build_universal_bracket_order` to generate the risk-sized `alpaca_bracket_order` payload and displays the full ticket.
5. Waits for the user to reply `Confirmed` before calling `sync_or_execute_alpaca` to submit the bracket order.
